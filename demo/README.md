# Violet product tour

A curated, read-only replay of the fictional Marcus Doyle case and selected Home actions. Nine scenes cover cross-case work, a request, the plan, interview summary, timeline, evidence, findings, report, and support.

`capture.js` and `expanded-capture.js` contain curated captured artifacts. `demo.js` controls navigation, transcript citations, allegation disclosures, and audio. The app stylesheet is isolated in an iframe. The parent and child exchange only same-origin playback and height messages.

Content is shortened for presentation. Interview markers open the corresponding transcript passages. Evidence alignment and the separate human support reply reflect the current Threads components. The report contains prose only, not copied hidden dialogs. Audio is a reenactment using Violet's configured voice and a separate synthetic investigator voice; this tour never opens a microphone or connects to live cases.

Run the repository build to copy the complete tour into `dist/demo`. Both root static hosting and the Vite production output are supported. The original pricing, contact, legal, and other static routes remain in place.
