case disambiguation, plan/interview progression, transcript prerequisites,
existing work, interruption and case-bound proposals. Run `node --test sandbox/flow.test.js`.

state context with the request to the existing bounded local gateway.

real uploads, other witness branches, full intake/policies and analysis progression.
